# Astro Kovesh 0.1.0

Primeira release funcional do ecossistema Astro Kovesh.

## Escopo entregue

- API publica com `GET /health` e `POST /v1/chart`
- frontend SolidJS para consulta e visualizacao do mapa
- deploy separado de API e Web na Vercel
- contratos compartilhados entre os repositorios
- compose local para subir stack completa

## O que foi estabilizado

- contrato HTTP alinhado com a implementacao
- formato de erro padronizado em `detail.code` e `detail.message`
- configuracao de ambiente revisada para desenvolvimento e Vercel
- importacao tolerante da engine astrológica em runtime serverless
- instalacao de `pyswisseph` no runtime de producao

## Validacoes executadas

- `pytest -q` na API
- `bun run test` no Web
- `bun run build` no Web
- `docker compose config` no repositório pai

## Compatibilidade

- Web `0.1.0`
- API `0.1.0`

Status: compativel e operacional.
