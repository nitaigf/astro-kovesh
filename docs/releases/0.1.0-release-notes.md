# Release Notes - v0.1.0

## Astro Kovesh 0.1.0

Primeira release funcional do ecossistema Astro Kovesh.

Esta versão entrega a base operacional do produto com API pública, frontend web e deploy independente dos dois serviços.

## Destaques

- API pública para cálculo astrológico com `GET /health` e `POST /v1/chart`
- frontend web em SolidJS para consulta e visualização do mapa
- deploy separado de API e Web na Vercel
- contratos compartilhados entre frontend e backend
- stack local orquestrada via Docker Compose

## O que foi estabilizado nesta release

- contrato HTTP alinhado com a implementação real
- formato de erro padronizado com `detail.code` e `detail.message`
- configuração de ambiente revisada para desenvolvimento e produção
- estrutura de deploy da API ajustada para Vercel com `Root Directory=api`
- instalação da engine astrológica incluída no runtime de produção

## Tecnologias

- API: Python, FastAPI, Pydantic, Geopy, TimezoneFinder, Swiss Ephemeris
- Web: SolidJS, Vite, TypeScript, Bun, Three.js

## Validação do marco

- testes automatizados da API executados com sucesso
- testes e build de produção do frontend executados com sucesso
- configuração do Docker Compose validada no repositório pai
- fluxo principal funcionando ponta a ponta
